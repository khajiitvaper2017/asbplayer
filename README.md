# asbplayer-jiten

This fork is for mining words from videos into [Jiten](https://jiten.moe/).

With it, you can:

- load subtitles onto local and streaming video;
- move through the video using the subtitles;
- capture the sentence, image, and audio;
- send the result to Jiten;
- mine new words from Jiten Reader with image/animation and audio.

## Getting started

1. Install Jiten Reader and create or choose a mining deck.
2. Open the [web app](https://asbplayer-jiten.pages.dev/asbplayer) or install the [browser extension](https://github.com/khajiitvaper2017/asbplayer/releases).
3. Open Settings and set **Mining destination** to **Jiten**.
4. Enter your Jiten API key.
5. Load a video and subtitles.
6. Use the mining button to review a subtitle, or set it to **Mine new words**.

See the [Jiten mining guide](docs/docs/guides/jiten.md) for more details.
