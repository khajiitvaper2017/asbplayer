# One-click mining {#one-click-mining}

For the Jiten workflow, one-click mining is handled by Jiten Reader integration.

1. Set **Mining → Mining destination** to **Jiten**.
2. Set **Mining → Mining button default action** to **Mine new words to Jiten**.
3. Let Jiten Reader process the loaded subtitle.
4. Trigger the mining button or its keyboard shortcut.

asbplayer sends qualifying new words to the selected Jiten mining deck and attaches the configured sentence, image, and audio context.
