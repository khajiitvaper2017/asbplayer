I made **asbplayer-jiten**, a Jiten-focused fork of asbplayer that helps you mine words from subtitled videos.

Use the [web app](https://asbplayer-jiten.pages.dev/asbplayer) with local video files, or install the [browser extension](https://github.com/khajiitvaper2017/asbplayer/releases) to work with streaming video. The [user guide](https://asbplayer-jiten-docs.pages.dev/docs/intro) covers setup and the complete workflow.

<!-- truncate -->

## Features

- Load subtitles onto local and streaming video.
- Move through a video using its subtitles.
- Capture the current sentence, image, and audio.
- Send mined cards directly to [Jiten](https://jiten.moe/).
- Mine new words from Jiten Reader and attach sentence, image, and audio context.
- Review and edit each card before sending it to Jiten.

## Getting started

1. Install [Jiten Reader](https://jiten.moe/), then create or select a mining deck.
2. Open the [asbplayer Jiten web app](https://asbplayer-jiten.pages.dev/asbplayer), or install the [browser extension](https://github.com/khajiitvaper2017/asbplayer/releases).
3. In Settings, set **Mining destination** to **Jiten**.
4. Add your Jiten API key, then load a video with subtitles.

Read the [Jiten mining guide](https://asbplayer-jiten-docs.pages.dev/docs/guides/jiten) for instructions on automatic context attachment, mining buttons, and troubleshooting.

I don't use the asbplayer extension myself, so I may have missed something. You will probably need to enable developer mode to install it.

A lot of features unrelated to Jiten were cut from this fork, and some documentation is outdated—sorry!
Create [an issue on GitHub](https://github.com/khajiitvaper2017/asbplayer/issues) if you encounter something that is not working as intended, or create a pull request.

Support for Jiten in upstream asbplayer will probably come with [plugin support](https://github.com/asbplayer/asbplayer/pull/1340#issuecomment-6159949130).
